# Inked explainer

A film in this style is **a function of the frame number**: every chapter is a React
component that draws SVG for `useCurrentFrame()`, on a timeline where every cut lands on
a bar line of music that is itself generated from the same timeline. Nothing is keyframed
in a tool, nothing is sampled, nothing is downloaded.

The template in `template/` is a complete, rendering example (a 17.6 s self-referential
demo, 1920×1080 and 1080×1920 from the same files). **Copy it; do not start from a blank
Remotion project.**

## Workflow

1. **Study the brief and any reference.** If the user sends reference videos, pull frames
   (`ffmpeg -vf "fps=1/2,scale=480:-1,tile=5x5"`) and read the spectrogram of the audio
   (`showspectrumpic`) before writing anything. Note: pacing (seconds per chapter), how
   titles enter, which ground each chapter uses, what carries the action, the sound (music + SFX
   density), loudness (`ebur128`).
2. **Write the chapters on a bar grid** in `src/film/timeline.ts`: 60 fps, a BPM (150 →
   a bar is 96 frames), each chapter a whole number of bars (2 bars = 3.2 s is the
   default beat; 3–4 for a chapter with more to show; 3–4 for the end card). Alternate
   `paper` and `night` grounds. Titles are lowercase, 3–5 words, a claim not a label
   ("hold to mark it caught", not "Holding"). Stage captions group chapters
   ("1 · plan", "2 · draw"). Extra cuts (a 30 s store preview, a teaser) are lists in
   `CUTS`.
3. **Copy the template** (`cp -R template <project>/film && npm install && npm run assets`)
   and rename the demo scenes. The template has **no character**: drawn props (a pencil, a
   metronome, a pen nib) and stickers carry the story. If the brief brings the user's own
   character, draw it in code from their art as a posable component; never invent one.
4. **Draw each chapter** as `scenes/<Chapter>.tsx`: a `Stage` (ground, camera, the `#ink`
   wobble layer, a crisp layer for text), the beat shape (establish 0–40 · action 40–130 ·
   payoff 130–170 · lean-in to the cut), lots of secondary motion, one clear focal action.
   Derive every position from `useVideoConfig()` so one file serves 16:9 and 9:16.
   Recipes: `references/scene-recipes.md`. Look: `references/style-guide.md`. Timing:
   `references/motion-and-timing.md`.
5. **Sound**: each scene exports `cues` (SFX in its local frames, from the vocabulary in
   `sfx.ts`). Re-run `npm run assets` after any timing change — the music reads
   `timeline.ts`. `references/sound-design.md`.
6. **QA with stills, not by imagining**: render stills at the key frames of every chapter,
   tile them into contact sheets and look; check every cut; check the portrait crop; check
   loudness with an audio-only render. `references/qa-checklist.md`.
7. **Render**: `npm run render` (and `render:vertical`). Make a share encode
   (`crf 21`, `+faststart`) next to the master.
8. **Optional cuts**: vertical for socials, a ≤30 s store preview —
   `references/vertical-and-store-cuts.md` (read the App Review notes there first).

## Hard rules

- **Everything in code.** SVG per frame; sound synthesised by `scripts/make-audio.mjs`;
  textures generated by `scripts/textures.mjs`. The only bitmaps are those generated
  textures and art the user owns and supplies. Never download stock footage, music, SFX or
  fonts outside Google Fonts via `@remotion/google-fonts`.
- **Never** CSS transitions/animations or Tailwind animation classes — they do not render.
  Everything moves through the frame number.
- **Cuts land on bar lines.** A chapter is a whole number of bars; retime in
  `timeline.ts`, never inside a scene.
- **Text stays crisp**: titles, chips and numbers go in `Stage`'s `crisp` layer, never
  under the `#ink` wobble.
- **Real numbers only.** Any count or price a film states must come from the product's
  data (generate a `stats.generated.ts` from it), never invented.
- **Other people's characters and marks**: do not draw or feature third-party characters
  or logos the user does not own; say so if the brief asks for them.
- **Verify before claiming done**: stills + contact sheets for every chapter, a loudness
  measurement, and a final render that actually finished (read the log's exit, `ffprobe`
  the file).

## Files

- `template/` — the working project (see its `src/film/**` JSDoc headers).
- `references/style-guide.md` — grounds, ink, palette, type, stickers, props, grain.
- `references/motion-and-timing.md` — the bar grid, beat shape, easing, camera, aiming a prop.
- `references/sound-design.md` — the synthesised bed, SFX vocabulary, mix and loudness.
- `references/scene-recipes.md` — patterns with code: a prop that hits its mark, hold rings, counters,
  receipts, stamps, radar sweeps, matrices, stars, orbits, end cards.
- `references/vertical-and-store-cuts.md` — portrait re-composition, crops, store specs.
- `references/qa-checklist.md` — how to look at what you made.
